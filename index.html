Methane (CH₄) reactions

Halogenation (400°C / UV)

+ Cl₂ → CH₃Cl chloromethane  |  + 2Cl₂ → CH₂Cl₂ dichloromethane
+ 3Cl₂ → CHCl₃ chloroform  |  + 4Cl₂ → CCl₄ carbon tetrachloride

Complete burning: CH₄ + 2O₂ → CO₂ + 2H₂O + E
1000°C / no air: CH₄ → C (black carbon) + 2H₂
Water gas (725°C, catalyst): CH₄ + H₂O → CO + 3H₂
Rapid quenching (1500°C): CH₄ → C₂H₂ + 3H₂

Ethene (CH₂=CH₂) reactions

+ Br₂/CCl₄ → CH₂Br–CH₂Br 1,2-dibromoethane (pi bond test)
+ HBr → CH₃CH₂Br bromoethane
+ H₂ / Ni 150–300°C → CH₃–CH₃ ethane
+ H₂O / KMnO₄ alkaline → CH₂OH–CH₂OH ethylene glycol
Dehydration (180°C, conc. H₂SO₄): Ethanol → Ethene + H₂O
Hydration (110°C, dil. H₂SO₄): Ethene + H₂O → Ethanol

Ethyne / Acetylene (HC≡CH) reactions

Preparation: CaC₂ + 2H₂O → C₂H₂ + Ca(OH)₂
+ HOH / H₂SO₄ 40%, HgSO₄, 60°C → CH₃CHO acetaldehyde
+ HCl → CH₂=CHCl vinyl chloride (1-chloroethene)
+ 2HCl → CH₃CHCl₂ 1,1-dichloroethane
+ Br₂ (step 1) → 1,2-dibromoethene  |  + Br₂ (step 2) → 1,1,2,2-tetrabromoethane
Trimerization (red hot Ni): 3C₂H₂ → C₆H₆ (benzene)
Complete burning (oxyacetylene): 4CO₂ + 2H₂O + energy (5000°C)

Benzene (C₆H₆) reactions

Addition reactions

+ 3H₂ / heat/pressure/cat → C₆H₁₂ cyclohexane
+ 3Cl₂ (UV) → C₆H₆Cl₆ Gamixane (BHC)

Substitution reactions (FeCl₃ controls)

Halogenation: C₆H₆ + Cl₂ → C₆H₅Cl + HCl (UV/FeCl₃)
Friedel-Crafts: C₆H₆ + CH₃Cl → C₇H₈ + HCl (anhydrous AlCl₃)
Nitration: C₆H₆ + HNO₃ → C₆H₅NO₂ + H₂O (conc. H₂SO₄, 50°C)
Sulphonation: C₆H₆ + H₂SO₄ (conc.) → C₆H₅SO₃H + H₂O

Key rules & exam tricks

• Markovnikoff's rule → only for asymmetric alkene/alkyne + asymmetric reagent
• Bromine water decolorizes = pi bond present (alkene or alkyne)
• FeCl₃ = controller of benzene substitution reactions
• O-substituent directs meta, EXCEPT –OH → ortho & para
• Hydration of ethene → primary alcohol; any other alkene → secondary or tertiary
• 1st symmetric alkene/alkyne = Ethene / Ethyne
• 1st asymmetric alkene/alkyne = Propene / Propyne
• Dry distillation of sodium acetate (2C) → methane (1C)
• Thermal decomposition of ethyl hydrogen sulphate → ethene
• Hydrolysis of ethyl hydrogen sulphate → ethanol
• Catalytic reforming of heptane → toluene
• Use Br₂/CCl₄ to differentiate alkane (single bond) vs alkene/alkyne (pi bond)
